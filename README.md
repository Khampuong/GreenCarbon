# GreenLoop Net Zero

**ส่งต่อเทคโนโลยี เพื่อโลกที่ยั่งยืน** — Powered by GreenDigital

เว็บแอปพลิเคชัน Green Digital ที่รวม GreenLoop (ตลาดอุปกรณ์ดิจิทัลมือสอง + รีไซเคิล E-Waste + Green Point)
เข้ากับ Net Zero Man (คำนวณคาร์บอนฟุตพริ้นท์รายปี) ให้เป็นวงจรเดียว: **วัด → ลด → รับแต้ม → ติดตามสู่ Net Zero**

เทคโนโลยี: PHP 7.3+ / 8.x · MySQL หรือ MariaDB · Bootstrap 5 · Chart.js (ทำงานบน XAMPP)

**ระบบทำงานได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต** Bootstrap และ Chart.js อยู่ใน `assets/vendor/`
ใช้ฟอนต์ของเครื่อง ไอคอนเป็น emoji และไม่มีการเรียก CDN หรือ API ภายนอก

## การติดตั้ง (XAMPP)

1. คัดลอกโฟลเดอร์นี้ไปไว้ที่ `C:\xampp\htdocs\GreenCarbon`
2. เปิด Apache และ MySQL ใน XAMPP Control Panel
3. เปิด phpMyAdmin → Import → เลือกไฟล์ `database.sql` (ไฟล์สร้างฐานข้อมูล `greencarbon` พร้อมข้อมูลตัวอย่างให้เอง)
4. หากฐานข้อมูลไม่ได้ใช้ `root` / ไม่มีรหัสผ่าน ให้แก้ค่าใน `config.php`
5. เปิด `http://localhost/GreenCarbon/`

ทางเลือกสำหรับทดสอบโดยไม่ใช้ Apache: `php -S localhost:8000` ในโฟลเดอร์โปรเจกต์
(โหมดนี้ไม่อ่านไฟล์ `.htaccess` จึงใช้สำหรับพัฒนาเท่านั้น)

## แนวคิดการเชื่อมโยงสองระบบ

ทั้งสองระบบใช้หน่วยเดียวกันคือ **kgCO₂e** และเชื่อมกันด้วยตาราง `green_activities` ซึ่งเป็นบัญชีกลางของทุกกิจกรรม

1. **วัด** — สมาชิกกรอกแบบคำนวณคาร์บอนฟุตพริ้นท์รายปี (พลังงาน เดินทาง อาหาร ขยะ อุปกรณ์ดิจิทัล)
   สูตร: ปริมาณที่กรอก × ค่าสัมประสิทธิ์ × จำนวนรอบต่อปี
2. **ลด** — ซื้อ-ขายมือสองและรีไซเคิล E-Waste ถูกแปลงเป็น kgCO₂e ที่ลดได้ตามค่าของหมวดอุปกรณ์
3. **รับแต้ม** — กิจกรรมเดียวกันให้ Green Point ระดับสมาชิก อันดับ และแลกของรางวัลได้
4. **ติดตาม** — หน้า "คาร์บอนฟุตพริ้นท์" แสดงแถบ % สู่ Net Zero = คาร์บอนที่ลดได้ในปีนั้น ÷ ฟุตพริ้นท์ของปีนั้น

ฟังก์ชันที่ตัดออกจากแบบร่าง GreenLoop เดิมเพราะซ้ำซ้อนหรือไม่เกี่ยวกับสิ่งแวดล้อม:
Digital Market, Wallet และการเติมเงิน, แชท (แทนด้วย "แจ้งปัญหา"), Premium, โปรโมทสินค้า, รายการโปรด, Achievement (รวมเป็นระดับสมาชิก), ตั้งค่าเว็บไซต์
ส่วนแบนเนอร์ ข่าว และแคมเปญ รวมเป็น "จัดการเนื้อหา" ตารางเดียว

### ระบบกำหนดวันเวลาโพสต์

เนื้อหาแต่ละรายการมี `publish_at` (เริ่มแสดง) และ `expire_at` (สิ้นสุด เว้นว่างได้)
หน้าเว็บดึงเฉพาะรายการที่เวลาปัจจุบันอยู่ในช่วงดังกล่าว จึงไม่ต้องตั้ง cron หรือ Task Scheduler
สถานะในหน้าผู้ดูแลคำนวณจากเวลาเซิร์ฟเวอร์: รอเผยแพร่ / กำลังแสดง / หมดอายุ / ปิดการแสดง
แคมเปญแต้มคูณใช้ช่วงเวลาเดียวกันนี้ควบคุมตัวคูณ Green Point

### รายงานและการพิมพ์

รายงานผลกระทบ Green Digital · คาร์บอนฟุตพริ้นท์รายปี · การรีไซเคิล E-Waste · ข้อมูลสมาชิก · เนื้อหา

- **กรอง / ค้นหา** — ช่วงวันที่ ตัวกรองตามชนิดรายงาน และคำค้น
- **กราฟ** — Chart.js แสดงตามข้อมูลที่กรองแล้ว
- **พิมพ์ / บันทึก PDF** — ปุ่มพิมพ์ใช้รูปแบบสำหรับกระดาษ A4 (มีหัวรายงาน เงื่อนไข ผู้พิมพ์ วันเวลา) เลือก "Save as PDF" ในหน้าต่างพิมพ์เพื่อได้ไฟล์ PDF
- **ส่งออก Excel** — ไฟล์ CSV แบบ UTF-8 พร้อม BOM เปิดใน Excel แล้วภาษาไทยแสดงถูกต้อง

## กติกาของระบบ

| กิจกรรม | Green Point | คาร์บอนที่ลดได้ |
| --- | --- | --- |
| คำนวณฟุตพริ้นท์ครั้งแรกของปี | +30 | — |
| ขายมือสองสำเร็จ | +20 | ครึ่งหนึ่งของค่าใช้ซ้ำของหมวด |
| ซื้อมือสองสำเร็จ | +10 | ครึ่งหนึ่งของค่าใช้ซ้ำของหมวด |
| รีไซเคิล E-Waste | +20 ต่อ กก. (ขั้นต่ำ 10) | น้ำหนัก × ค่ารีไซเคิลของหมวด |

ค่าทั้งหมดแก้ไขได้ที่เมนู "ตั้งค่า Green" ระดับสมาชิกคิดจากแต้มสะสม: เมล็ดพันธุ์ → ต้นกล้า (100) → ต้นไม้ (300) → ผืนป่า (600) → Net Zero Hero (1,000)

**ค่าสัมประสิทธิ์การปล่อยและค่าคาร์บอนของหมวดอุปกรณ์ใน `database.sql` เป็นค่าประมาณสำหรับสาธิต**
ควรตรวจและปรับให้ตรงกับค่าอ้างอิงล่าสุดของหน่วยงานที่เชื่อถือได้ (เช่น อบก.) ก่อนนำเสนอ

## ความปลอดภัย

- รหัสผ่านและคำตอบกันลืมเก็บด้วย `password_hash` ตรวจด้วย `password_verify`
- ทุกหน้าที่ต้องเข้าสู่ระบบเรียก `require_login()` ทุกหน้าใน `/admin` เรียก `require_admin()`
- Session หมดอายุเมื่อไม่ใช้งาน 30 นาที เปลี่ยน session id เมื่อเข้าสู่ระบบ และตรวจสถานะระงับสิทธิ์ทุกคำขอ
- ทุกฟอร์ม POST มี CSRF token ทุกคำสั่ง SQL ใช้ prepared statement ทุกค่าที่แสดงผ่าน `htmlspecialchars`
- ตรวจสอบข้อมูลทั้งฝั่งเบราว์เซอร์และฝั่งเซิร์ฟเวอร์ โฟลเดอร์ `uploads/` ห้ามรันสคริปต์
